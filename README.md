# Team Codex Skills

Shared Codex skills for Amazon operations and product image workflows.

## Included skills

- `product-inspiration-search`: collect and review Pinterest inspiration with source records.
- `product-reference-images`: generate product visual reference images from themes and references.
- `product-image-restyle`: replace a defined artwork or background area while preserving protected product structure.
- `blanket-aplus-design`: create seven 970x600 English, unbranded A+ images for a blanket parent listing.
- `blanket-scene-components`: build reusable blanket backgrounds, compositions, visual styles, and information components.
- `blanket-listing-images`: create the existing blanket listing-image package.

Install a skill by copying its directory under your Codex skills directory. The image workflows expect the shared image runtime and its local configuration to be installed separately; credentials are never included in this repository.

These skills generate local files and previews. They do not publish Amazon listings or submit marketplace changes.
