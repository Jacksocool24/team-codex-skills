# 参考图设计适配 v1.1

生成前及视觉返工时读取[共同方法](../../../skill-library/design-methods/impeccable-raster.md)。本分支优化的是平面图案创意，不默认变成商品摄影或信息图。

## 提示词与执行

- 先写主体、辅助元素、密度、色彩限制和构图类型；用户要求单张完整场景时禁止拼图、分屏、九宫格，不轮换成其他构图。重复纹样只有当前需求允许时使用。
- 黑白主题只用黑白灰，通过明度、尺度和疏密形成节奏；不自动添加“高级金色”、渐变或新品牌。彩色主题保留用户指定配色，不为统一风格擅自换色。
- 中心人物/动物保持完整，装饰围绕核心服务；重复纹样检查间距与边缘衔接，但未经拼接验证不宣称无缝。
- `workflow.py`的新任务提示词已带焦点、密度和配色约束。具体单幅/布局要求写入 `--style`，显式需求优先于默认构图轮换。先 `--dry-run` 检查保存的每条任务，再执行同一计划（`--resume`）；旧计划续作不重写提示词。
- 新图只借鉴灵感的通用元素与配色，改变具体构图和元素组织；相似度低不等于法律上的不侵权保证。

## 审核与例子

例如“黑白圣诞高地牛，完整单幅”：主体是高地牛，圣诞植物为次要元素，以灰阶深浅区分空间；不加入文字、家居场景、六格拼贴或彩色饰品。若缩略图先看到花边而非牛，优先降低允许改动的装饰密度，不删除核心主题。

全尺寸检查重复肢体、主体裁断、伪文字和非预期拼图；375px检查主题能否识别。多张可有不同场景，但应遵守同一主题/配色约定，不能只用镜像或调色冒充新设计。记录视觉结论到现有任务记录；脚本尺寸/hash检查不替代看图。原有PNG、预览、任务与参数交付保持不变。
