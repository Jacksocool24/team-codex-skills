# 商品参考图生成 v1.1

## 本次设计方法更新

v1.1（2026-10-31）：参考图增加焦点、配色、疏密与单幅完整性检查；保留原有输出与主题参数。 旧版名称继续对应稳定调用标识，不新增重复技能。
生成前和视觉返工时读取[设计适配与检查](references/design-review.md)，按其中链接使用共用的Impeccable位图适配方法：明确目标与锁定区域，选择必要调整，检查最终成图。只改文字/布局时优先本地处理，方法检查并入已有审核，不增加默认交付物或审图接口。

稳定调用标识：`$product-reference-images`。

本技能用于探索商品视觉方向。用户可以只提供产品名称、主题元素或节日元素；缺少细节时使用本文件的默认规则，并在任务记录中写明推断内容。尺寸、数量、颜色和风格都是参数，不为每个产品或主题复制新技能。

## 输入

- 必填：产品名称或主题元素；只给主题时使用通用商品视觉参考图作为产品上下文。
- 可选：一张参考图或参考图文件夹。支持 PNG、JPG、JPEG、WebP、TIFF、BMP。
- 可选：生成数量，默认 4 张；输出尺寸，默认 `1145×1374`；配色、视觉风格、季节或市场说明。
- 默认市场：美国；默认语言：英文视觉语境；默认画面不含可读文字。

用户只说“做万圣节黑猫毛毯参考图”时，直接把“万圣节、黑猫”作为主题，自动补充月亮、南瓜、幽灵、秋叶等相关元素，并保留毛毯印花适用性。

## 默认生成规则

1. 先解析产品、主题、季节、颜色和使用场景，建立本批次的主题说明。
2. 生成多张有差异的构图：主体聚焦、重复纹样、故事性插画和边框或徽章构图按数量循环使用。
3. 主题元素保持一致，变化来自构图、视角、密度、配色和留白；不要把同一批图做成互不相关的主题。
4. 面向美国消费者的家居和礼品审美，使用清晰主体、协调配色、适度季节氛围和可印刷的完整画面。
5. 对毛毯、地垫、地毯等表面图案，优先生成平面、满幅、可重复理解的装饰设计；不要默认生成商品摄影、模特、家具场景或亚马逊信息图。
6. 不使用品牌标志、受版权保护的角色、名人、球队标志、仿制商标、可读宣传文字、水印、价格和平台界面。
7. 重要主体放在中央安全区域，避免被裁切；背景细节服务于主题，不遮住主元素。
8. 参考图用于保留主题、配色或构图方向，不机械复制未经确认的品牌、角色和文字。参考图明显要求“照抄”时，改为提炼可泛化的视觉特征。

详细的主题扩展和提示词结构见 [references/prompt-guidelines.md](references/prompt-guidelines.md)。

## 输出

- `reference-01.png` 等参考图，默认最终尺寸为 `1145×1374`；原始模型输出尺寸和最终尺寸分别记录。
- `reference-overview.jpg` 和 `index.html` 预览页。
- `generation-jobs.jsonl`：每张图的完整提示词、可选参考图和生成参数。
- `generation-manifest.json`：输入、输出、哈希、尺寸、状态和检查结果。
- `README.txt`：本批次假设、主题说明、限制和后续建议。

## 执行流程

使用本机 Python 和共享图像运行时。共享运行时负责读取中转配置和密钥；本技能不读取、不复制、不记录密钥。

```powershell
& '<PYTHON>' -X utf8 `
  '<CODEX_HOME>\skills\product-reference-images\scripts\workflow.py' `
  --product '成品法兰绒毛毯' `
  --theme '万圣节' --theme '黑猫' --theme '月亮' --theme '南瓜' `
  --output 'D:\path\商品参考图批次'
```

仅建立任务清单、不调用付费接口时，加 `--dry-run`。已有成功文件需要续作时，加 `--resume`；不要因一次失败盲目重复生成，先检查 `generation-manifest.json` 和服务商请求记录。

参考图可通过 `--references` 指定文件或文件夹。使用参考图时，脚本会将本地图片路径写入对应任务，交给共享运行时的图像编辑入口；不把图片上传到技能目录。

## 检查标准

- 数量与文件名连续，全部为可读取 PNG。
- 最终像素尺寸准确，输出哈希和原始模型尺寸写入 manifest。
- 每张图主题至少包含用户指定的核心元素，且同一批次风格和调色方向一致。
- 主体完整、没有明显裁切、拉伸、重复人物、乱码文字、水印或平台标识。
- 对商品表面图案，检查画面是否足够平整、完整、可供后续商品图或印花适配使用。
- 参考图只作为视觉依据；不得把概念图描述成已验证的生产稿、真实包装或已具备的产品性能。

程序检查只能证明文件、尺寸和记录完整；主题一致性、版权风险和设计可用性仍需要目视确认。此技能只生成本地参考图，不自动上架商品、不提交亚马逊、不下生产订单。
