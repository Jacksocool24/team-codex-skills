# 构图库 v1.0

规则真源为`assets/compositions/catalog.json`。背景库保持独立；商品、背景和构图按引用组合，不把某个父体或图片路径写死到模板。稳定模板标识用于调用，实际实例另存审核。

## 六个方向与适用范围

| 标识 | 方向 | 执行方式 |
| --- | --- | --- |
| shallow-fan-4 | 浅弧扇形 | 本地旋转、缩放与叠放；系列氛围，允许有限边缘遮挡 |
| hero-support-4 | 一主多辅 | 本地排版；第一个输入为主款，其余完整缩略展示 |
| aligned-flatlay-4 | 整齐平铺 | 本地排版；四款等权，零遮挡，优先准确选款 |
| staggered-steps-4 | 错落阶梯 | 本地排版；同尺度四款高低递进，不暗示尺寸不同 |
| scene-and-selection-4 | 场景主图＋款式陈列 | 已审核同款无字场景＋四款原图本地排版；未完成首轮实图验收 |
| folded-stack-4 | 折叠堆叠 | 使用现有场景生成流程和专用构图提示，不能压扁原图伪装折叠；未实图验收 |

目前参数仅4款。首轮对照为前三项，阶梯为补充实例。10款要另行设计分行或减少重叠，不直接套4款参数，也不以重复四款充当十款验证。

每项记录：画布、适用款数、产品中心位置、容纳宽高、旋转角度、z顺序、遮挡上限/规则、文字位置、手机检查状态、适用目的、限制和后续灵感检索词。缩放为contain保持原比例；真正使用的缩放比记录在实例`checks.json`。坐标不等于产品实物尺寸。

## 本地执行

`<PYTHON> -X utf8 <技能>/scripts/layout.py --brief <brief.json> --template <标识> --out <不存在的新工程目录>`

```json
{
  "mode": "finished",
  "headline": "Find your favorite print.",
  "subline": "Choose one design. Four sizes available.",
  "background_color": "#ffffff",
  "ink": "#202b2d",
  "products": [
    {"id":"style-01","label":"Harvest","path":"D:/.../front-01.png","remove_connected_white":true,"white_threshold":245,"protected_box":[0.32,0.22,0.65,0.70]}
  ]
}
```

实际调用需完整四项products，唯一ID，短英文标签，源图不能虚构。可选background为独立970×600背景；首次对照三版保持相同背景、文案、来源和顺序，只变构图。场景＋陈列额外需要`scene:{path,design_id,review_path}`；review文件含`scene_sha256`与`status:accepted`，由实际目视核对后登记。

白底自动移除只处理与画布边缘连通的近白区。它可能误删与背景连通的白色包边或白图案，必须对照原图看去底结果；复杂背景改用人工核对的mask_path。产品可以已有透明通道。crop_box只可裁掉外边距，不裁印花主体。没有需求不要生成新图片替代现有图案。

protected_box相对去外边距后的产品图，以[左,上,右,下]归一化表示，逐款定位脸部、文字或主图案；不能为了通过遮挡检查缩小保护区。多个远离的重点需扩大保护区或选零遮挡构图。统计遮挡是几何筛查，不能代替人脸/图案目视核对。

## 审核与登记

检查输出准确970×600、产品唯一覆盖、原比例、图案内容、包边、蒙版、文字、层序及实际遮挡。原图旋转和缩放仍有重采样，不宣称输出像素与原图一一相同；这里只保证无生成式重绘。

查看final.png、mobile.png和sources内去底图。审核文件绑定成图SHA、模板SHA、源图SHA；标记“4款该实例通过”，不要标记所有主题/数量全通过。失败修配置或遮罩，不调用生图补救本地排版问题。

几何记录包含每款遮挡比例、保护区遮挡比例、实际bounds、缩放、旋转和层序。标题/标签区域自动检查碰撞；阴影为本地示意，不代表真实光照或面料厚度。

可浏览实例、手机审核与本地图索引放`<WORKSPACE_ROOT>/skill-library/composition-library/v1.0/`。index.json保存审核与预览路径；工作台在此技能详情显示“构图库”，区分已审核样例和待实图验证规则。模板真源仍在技能assets目录，不改背景库路径。独立HTML为本地图册，不需要公网或新API。
