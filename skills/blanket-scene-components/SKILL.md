# 毛毯场景部件制作 v2.2

## 本次设计方法更新

v2.2（2026-10-31）：在独立部件流程中加入设计诊断、单变量对照与验收后复用规则。 旧版名称继续对应稳定调用标识，不新增重复技能。
生成前和视觉返工时读取[设计适配与检查](references/design-review.md)，按其中链接使用共用的Impeccable位图适配方法：明确目标与锁定区域，选择必要调整，检查最终成图。只改文字/布局时优先本地处理，方法检查并入已有审核，不增加默认交付物或审图接口。

稳定调用标识 `$blanket-scene-components`；作图 → 场景部件制作。独立于现有“毛毯 A+ 内容设计 v4.0”，不覆盖或自动升级后者。遵循[工具库规范](../../skill-library/PRINCIPLES.md)，复用共享image-runtime，不复制接口、密钥或提供商配置。

v2.0增加独立构图库v1.0和原图本地排版分支，旧名称v1.0继续指向本稳定标识。升级前版本已归档在skill-library/backups。背景库决定环境，构图库决定位置与层级，商品素材决定内容；三个目录不混用。

v2.1新增可选的视觉风格配置与信息表达组件，本地后处理不改变既有场景/构图流程。旧名称v2.0仍可调用。当前只验证本机两套风格及4款成品试验，不自动替换默认配色或把试验等同于用户已选定风格。

## 输入与交付

- 输入：场景灵感图或已入库背景、商品参考图/印花原稿、成品或定制、款式/照片布局、拟展示尺寸、数量、输出目录及可选英文。无法从资料确定的规格不猜测。主题与尺寸是参数，不另建技能。
- 默认画布970×600、英文、无品牌名/商标/水印。数量遵循用户请求；未指定时先做一个代表组合，不自动铺开七图、全部尺寸或所有场景×款式。
- 交付目录只放本次最终PNG。背景、产品及接触区域、融合蒙版、文字层、提示词、输入哈希、375px预览与审核留在内部工程。严格照片还原未通过时明确交付为试验图。
- 不提交亚马逊，不自动发布素材。整套七图需求由现有A+技能承担；只有用户需要该流程时才调用，不篡改其文件。

## 先选择执行分支

- 保持背景与构图不变，调整配色、字体、层级和精简文案：读取[风格与信息组件](references/style-information.md)，使用`scripts/style_information.py`叠加文字到已锁定无字底图。款数、尺寸来自当前父体事实矩阵；不调色产品，不为材质实拍缺口添加生成证据。改文案与样式不调用生图。
- 多款扇形、选款陈列、构图对比：读取[构图库规则](references/composition-library.md)，使用实际毛毯图和`scripts/layout.py`本地排版，不调用生成模型重绘图案。第一版提供六个方向，四个本地模板有4款实例；场景陈列与折叠堆叠另行实图验证。构图未覆盖的款数不能机械扩展。
- 家居背景、沙发/椅子、真实折叠与接触：继续下面的场景融合流程；可借用构图区域，但不能用平面图片挤压模拟织物结构。
- 同一组对比固定素材、文案、画布与背景，变更构图；输出文件与手机审核绑定哈希。新增图册仅在构图库建立/查看请求时提供，普通作图仍交付最终PNG。

## 执行

1. 读取[执行约定](references/workflow.md)。盘点来源，区分实拍、原稿、商品效果图、授权背景及未确认授权的灵感图。检查成品/定制、照片数量/格序、包边、尺寸和可证明卖点。缺少材质实拍时不生成作为证据的微距。
2. 查阅[已验证场景入口](references/validated-scenes.md)，有适合的背景先校验文件及哈希。背景复用不要求品牌或款式相同，但须核对色调、光线、位置与文字区。不可直接把未经授权的Pinterest照片当作成图背景；参考其方向制作不同的新空间，来源状态保留。
3. 无可用背景时，以灵感图为参考生成无毛毯、无人、无字的新背景。先确定家具、机位、光线、产品区域与自然文字留白，验收后保存独立背景，不把首次整张生成当成所有后续款式的唯一源文件。
4. 使用已验收背景作为第一参考、指定毛毯作为第二参考，融合一款毛毯。提示词明确照片身份、数量、格序、包边、下摆终点、浅褶皱、接触阴影和文字禁入区。按实例写出实际图案，不把三图试验的沙发、动物或布局写死。提示词中的“精确保留”不是验收结论。
5. 目视对比背景和融合结果。若机位/家具大幅移动，只返工该融合；不能靠蒙版掩盖不匹配。必要时小范围纳入接触区域，但不要随意扩大到整图。使用`scripts/compose.py`按实际坐标合成，保存可重复运行的配置和图层，检查蒙版外像素不变以及文字不碰产品区域。
6. 桌面和375px逐图检查：人物面貌、格数与顺序、包边、褶皱、光影、家具连续性、下摆离地及文字可读性。将视觉审查绑定到最终文件SHA256；几何通过不能代替身份或材质真实性。允许记录“布局试验通过、照片保真未通过”，不可全部标为通过。
7. 交付并登记背景、坐标、提示词、依赖与审核。换款重新融合并审核；改字只用本地排版。失败仅修相关组合，保留已完成部分；同一问题最多两次针对性生图返工，仍有问题则交付已有结果并说明限制，不循环烧算力。

## 运行与复用

当前本机使用`<PYTHON> -X utf8`，本地合成依赖Pillow和numpy；生成使用`~/.codex/skill-library/image-runtime/generate.py`的现有配置，quality=high、并发最多2。不因提速降低质量或另配API。创建/维护本技能不意味着要发起新的付费生图。

背景任务与融合任务分别写JSONL，通过共享程序的`--dry-run`检查后，按已授权生成需求执行。详细任务格式、合成配置和复用办法见[执行约定](references/workflow.md)。合成工具只处理本地图片，不读取任何密钥。

透明前景层包含局部家具和接触阴影，只适用于相同背景与坐标；不是通用纯毛毯抠图。现阶段参考图引导生成会改变人物/动物细节。严格客户照片还原需求不能以本技能的生成结果冒充精准映射，需要另行验证原图变形贴图方案。
