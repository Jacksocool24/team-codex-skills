# 商品灵感素材检索 v1.0

稳定标识：`$product-inspiration-search`。作图 → 灵感素材检索。

## 输入与交付

接收产品、主题、风格、目标市场和可选输出目录。缺省市场美国、候选总数 30；用户没有选题时先询问主题，不能把示例高地牛锁定为所有产品。第一轮 20–30 张，验证访问及质量后才按需求扩大到 100–300 张，数量是上限而不是成功保证。

交付 `index.html` 可筛选预览、候选原图、`manifest.json`、`materials.csv`、`overview-*.jpg` 审阅缩略图及视觉审阅结果。每张保留原 Pin、图片 URL、搜索词、哈希、像素、可核实的发布时间/互动数据和推荐理由。检索脚本不生成虚假视觉结论。

## 执行

1. 理解产品的图案表面要求，用当前会话的模型能力扩展 3–6 个具体英文查询。主题词、风格词、产品用途分开考虑，避免所有查询完全相同，也避免只搜商品摄影。写 `plan.json`，格式见 [运行合同](references/workflow.md)。中文输入由当前执行技能的模型翻译，不要求用户自己提供英文。
2. 使用已配置的独立运行环境执行 `scripts/workflow.py collect --plan <plan.json> --output <新目录>`。首选固定版本 `pinterest-dl`；只有有根据的兼容问题才显式改用已配置的 `--engine gallery-dl`。登录、429 或网络阻断时停止，说明原因，不以换引擎绕过限制。会话文件仅在用户自行登录并提供本地路径时使用，不读取浏览器凭据或输出密钥。
3. 检查 manifest 的 `status`、`errors` 和数量。失败或不足时保留部分成果并如实报告；重复运行使用 `--resume`，成功查询和已取得的文件复用。不要把历史缓存当成新抓到的新图。
4. 必须用视觉工具查看 `overview-*.jpg`，再逐张打开候选原图或足够清晰的预览，特别是细节、裁切和水印不明确时。为每个技术检查通过的候选写 `reviews.json`：元素、配色、构图、推荐理由、缺点以及 `keep/reject`。依据见运行合同。近似重复需比较后判定，不能仅凭哈希相近断言是重复。无法目视检查的图保持待审，不填套话或编造分析。
5. 执行 `review --output <目录> --reviews <reviews.json>`。程序绑定每张文件 SHA256 并更新预览/CSV。只有全部候选完成视觉审阅才算本轮完成；没有合格素材也如实交付结果，不凑数。
6. 用户在预览勾选素材，下载 `selection.json`，或在聊天中指明编号。执行 `handoff --output <目录> --selection <selection.json>`，生成独立 `selected-references` 目录和 `generation-handoff.json`。只允许交接已审核保留的图。选择结果与当前批次绑定，不将整批未筛选图交给生成接口。
7. 用户要求继续创作时，调用已有 `$product-reference-images`，读取交接中的产品/主题/风格与参考目录，提炼通用元素、配色和构图方向生成差异化设计；复用该技能的共享图片运行时。单纯搜图不自动消耗生图额度。

默认命令（本机）：

```powershell

  '<CODEX_HOME>\skills\product-inspiration-search\scripts\workflow.py' `

```

## 模型与工具边界

确定性检索使用开源客户端，不需要图像模型或新中转密钥。关键词扩展和视觉审阅由调用技能的当前 Codex 会话执行，复用会话已有模型连接；本技能不另建分析 API 或复制凭据。后续生成继续使用现有共享 image-runtime。工作台 Skill 管理负责发现、查看、收藏和调用示例，本版没有无人值守模型执行器或网页一键采集按钮。

## 可观察检查

- 图片来自 Pinterest 图片域，能解码，像素达到本次阈值，来源可追溯；09 工厂图之类的商品图套装规则与本技能无关。
- 精确重复不重复入库，近似图显式分组，像素不足和损坏图片有原因记录。支持跨批次文件缓存，重跑不覆盖旧任务。
- 每个通过技术检查的候选都经过可追溯的视觉审阅；未审状态不可伪装为推荐。
- 发布时间和抓取时间独立；没有热度数据就标未知，不能把英文搜索结果称为美国近期热榜。美国只作为目标市场，不作为已验证受众来源。
- 不把网友作品视为已授权印刷稿。保留来源，提炼通用设计特征，排除明显标志/受保护角色/水印作品；AI 改写不等于取得商用权。
- 第一版不采集 Instagram、不自动追踪趋势、不发布商品。遇到访问限制保存故障和下一步，不无限重试或自动购买服务。
