# 成品毛毯商品图套装 v1.1

## 本次设计方法更新

v1.1（2026-10-31）：套图增加主次层级与跨图一致性审核；固定八张展示图加一张印花原图。 旧版名称继续对应稳定调用标识，不新增重复技能。
生成前和视觉返工时读取[设计适配与检查](references/design-review.md)，按其中链接使用共用的Impeccable位图适配方法：明确目标与锁定区域，选择必要调整，检查最终成图。只改文字/布局时优先本地处理，方法检查并入已有审核，不增加默认交付物或审图接口。

稳定调用标识：`$blanket-listing-images`。本技能是产品工作流，模型配置独立维护。
遵循 [工具库规范](../../skill-library/PRINCIPLES.md)：按独立用途组织、复用执行服务、明确输入输出与检查标准。

## 输入与默认值

- 用户指定的一张参考图，或文件夹中的全部参考图。PNG/JPG/JPEG/WebP/TIFF/BMP均可；文件夹递归扫描，按自然顺序逐款处理。
- 毛毯实际宽高，单位英寸，默认50×60。其他尺寸是参数，不另建技能。
- 保留已选参考图的主题和配色；仅按用户明确要求改变主题或颜色，并记录在任务参数中。
- 材质、背面、洗护、包装、工厂要求以用户确认事实为准。未知时只展示正面面料，礼盒和丝带标为道具，不声称不褪色或已达生产规格。

## 固定交付

每款恰好九张PNG：01白底正面、02尺寸图、03沙发、04卧室、05人物使用、06面料细节、07人物放入洗衣机、08礼品盒与丝带、09独立印花原图。
同时交付逐款预览、批次总览、ZIP、实际尺寸像素和提示词来源记录。
印花先确定，再供整套商品图引用。不得按九段无关文字分别生成九个不同设计。

读取 [九图工作流和检查标准](references/listing-workflow.md)。提示词源为 [八图模板](references/listing-prompts.json) 与 [印花模板](references/print-master-prompt.txt)。保留已批准的01与09模板，比例适配另加任务要求。

## 一次调用流程

使用本机 Python `C:\Python314\python.exe`，加 `-X utf8`。以下 `<skill>` 为本SKILL.md所在目录。

```powershell
python -X utf8 <skill>/scripts/workflow.py run --references 'D:\path\参考图' --output 'D:\path\新套装' --width 50 --height 60
```

`--references`也可指向单张图片。可选 `--theme`、`--palette`、`--packaging`。首次使用新输出目录；已知同一批次用 `--resume` 跳过保存且校验通过的图片。失败后先检查运行记录及服务商请求状态，不能盲目重发。

- 比例已匹配且不要求改主题/颜色：保留PNG原字节，其他格式无缩放转换为PNG并记录。
- 方形或其他不匹配比例：调用共享作图程序重新构图到目标比例；不拉伸、不随意裁掉边框。检查实际返回比例，不符合就暂停该款。
- 保留原始参考图、适配印花和来源哈希；第09张必须与本套实际采用的印花一致。
- 默认逐款执行，每款最多两个图像请求并行。失败停止，不自动重复收费；已有成功图保留。
- 每款完成后目视检查九图。程序验证只能证明数量、文件、比例和哈希，不能替代图案、人物和场景检查。
- 全部完成后打开总览并给出打包文件，说明实际原图像素及尚待确认的生产要求。

仅准备任务、无密钥读取和付费调用：在 `run` 命令添加 `--dry-run`。本地重新打包：

```powershell
python -X utf8 <skill>/scripts/workflow.py finish --folder 'D:\path\新套装\set-001'
python -X utf8 <skill>/scripts/workflow.py summarize --output 'D:\path\新套装'
```

详细参数和返工流程见 [执行与恢复](references/execution.md)。不要另写临时批次脚本重复已有流程。

## 执行引擎与边界

本技能的 `scripts/generate.py` 仅转交至 `../../skill-library/image-runtime/generate.py`（相对技能目录）。
共享引擎的 `provider.json` 集中管理用户选择的中转地址、模型别名和密钥文件路径；模型真实底层来源未独立验证。模型不是业务技能名称。
密钥仅执行时从原文件读取，不写入提示词、配置内容、日志、压缩包或聊天。中转仍是用户选择的HTTP服务，不擅自改提供商。

本技能只制作本地图像，不自动上架或下生产订单。生产稿须核对工厂像素、出血和颜色规格；1145×1374像素在50×60英寸下只有22.9PPI，不能称为已验证的印刷稿。
