# 固定七图设计与提示词规则

v3新项目以SKILL.md的精简交付及seven-module-prompts.md开头的v3约定为准。以下旧版具体字号/坐标仅作为legacy版式说明；新的交付不附带预览和报告，375px检查在内部完成。素材复用不降低high生成质量。

| 图 | 任务与排版 | 事实边界 |
| --- | --- | --- |
| hero | 一张宽幅使用照，左侧标题，右侧真实商品 | 代表款是系列示例；不能暗示只卖一款 |
| details | 主特写＋完整正面，简短说明 | AI图不能证明GSM、背面、厚度或性能 |
| designs | 4款一行；6/10款两行；自适应短标签 | 原始图拼版，不让模型重画款式 |
| lifestyle | 两个不同用途场景，分别标所示尺寸 | 各场景独立锁定印花 |
| sizes | 同尺度印花示意＋准确英寸数字 | 不以Baby/Teen等年龄标签代替尺寸 |
| care | 人物放毛毯进洗衣机，侧边确认过的规则 | 不推断温度、烘干、漂白、不褪色 |
| gift | 毛毯可见的赠礼互动＋短标题 | 包装未知不出现配套礼盒 |

## 三层制作

父体资料决定品牌、款式与共同事实；场景模板制作hero/living/bedroom/care/gift五个摄影素材；campaign本地组合图内文字、目录和尺寸。无字只约束中间素材。

场景中的文字预留区必须目视确认，不能让本地面板盖住商品。每次根据主题填写scene_context，不把四季混合父体的房间、人物或节日强加到其他产品。多个主题共用中性家居与统一光线，不改真实印花颜色。

## 提示词

workflow自动加入品牌、模式、身份锁定、风格、尺寸和无字约束。scene-prompts.json补充镜头、家具尺度、动作、图案与文字位置。完整结果保存在generation/jobs.jsonl，不只存占位符。

商品参考只用当前款式的对应尺寸白底图/印花原稿。竞品图用于理解版式，不作为人物、图案、商标或性能证据。每个scene的shown_size必须匹配所用参考图。

## 排版

- 最终970×600；数字与单位代码排版。四尺寸同一像素/英寸比例。
- 当前标题约43—48px，主要标签30—34px。手机必须实看；放不下时缩短内容，不无限缩字。模板字号不是平台规定。
- 6/10款目录用Style ID，完整名称在design-map保存。全部款式集合须与父体相同。
- 产品图和印花默认contain，不拉伸或切边。环境裁切也要检查没有裁掉商品。
- Windows Georgia/Arial缺失时明确失败，不默默换字体。

## 审阅

逐图记录identity、scale、text、claims及依据。检查主物是否被文字面板盖住，目录是否完整，尺寸比例是否准确，文案是否有事实支持。不用文件存在或模型自评代替观察。当前检查通过只代表本地设计稿完整；后台模块/图槽和ASIN仍需另查。
